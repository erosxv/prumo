# Prumo

Painel pessoal para organizar o dia, num único arquivo HTML, sem instalação e sem servidor.

- **Tarefas** com prioridade alta, média e baixa, edição com um clique e "desfazer" ao concluir ou excluir
- **Foco**: timer pomodoro com duração ajustável, tarefa associada e gráfico dos últimos 7 dias
- **Hábitos** com grade da semana e contagem de dias seguidos
- **Notas** com salvamento automático

## Como usar

Abra o `index.html` no navegador, ou acesse a versão publicada no GitHub Pages.
Atalho: tecla `N` para escrever uma nova tarefa.

## Onde ficam os dados

Tudo é salvo no `localStorage` do seu navegador. Nada é enviado para servidor nenhum.
Dados não passam de um navegador para outro; limpar os dados do site apaga o painel.
